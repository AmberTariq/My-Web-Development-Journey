# Project Description
Recently, I discovered a strong interest in front-end web development and jumped headfirst into building a solid foundation in HTML, CSS, and eventually JavaScript! Using fantastic learning platforms like Codédex, CodeSignal, and Alison, I've been mastering semantic structuring, styling layouts, and modern design principles.

Today, I am incredibly excited to share my very first milestone: a Personal Portfolio Webpage tracking my achievements and engineering journey!

Getting the syntax down, tackling layout boxes, and troubleshooting rendering glitches definitely wasn't easy. But the process of learning new semantic tags, experimenting with style formatting, and exploring design techniques kept me completely locked in—I was never bored for a single second. This hands-on process has only made me more passionate about frontend layout engineering.

**🛠️ Tech Stack Used:**
* **HTML5:** Semantic structuring (`<header>`, `<section>`, `<figure>`, `<nav>`)

CSS3: Reusable component classes, border architectures, custom shadows, and font typography styling

Workspace: vscode.dev in-browser IDE environment
